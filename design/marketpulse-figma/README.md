# MarketPulse · Maquettes Figma

Ce dossier contient 15 écrans vectoriels SVG (1440 × 1024), un fichier par frame, prêts à être importés comme éléments éditables dans Figma.

## Importer dans Figma

1. Décompressez l’archive `marketpulse-figma.zip`.
2. Dans Figma, créez un fichier et glissez-déposez un ou plusieurs SVG sur la page, ou utilisez **File → Place image**.
3. Les textes, formes, cartes, graphiques et contrôles sont vectoriels et peuvent être réorganisés et recolorés dans Figma.
4. Les zones de visuels produit des cartes sont des placeholders de maquette. Les données de marché affichées sont fictives.

Les SVG peuvent aussi être modifiés directement dans un éditeur vectoriel. Ils couvrent le tableau de bord, le catalogue, le détail produit, tendances, sentiment, prévisions, opportunités, gestion des données, alertes, rapports, paramètres, assistant IA et les trois écrans d’authentification.
